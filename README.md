# 🏥 אפליקציית זימון תורים - מרפאת ילדים ליברמת אפעל

## תיאור
אפליקציה web standalone לזימון תורים בתיקייה אחת, ללא צורך בשרת או טכנולוגיה מורכבת. האפליקציה עובדת 100% offline ושומרת את כל הנתונים בזיכרון המכשיר.

## 📋 תכונות

✅ **זימון תורים**
- בחירת תאריך מיומן חודשי
- בחירת שעה (10 דקות)
- הכנסת פרטי המטופל (שם, ת.ז, קופת חולים)
- אישור התור

✅ **ניהול תורים**
- תצוגת כל התורים המזומנים
- מחיקת תורים
- סטטיסטיקות (סך תורים, זמנים פנויים)
- ייצוא נתונים ל-JSON
- מחיקת כל הנתונים

✅ **טכנולוגיה**
- HTML5 + CSS3 + JavaScript
- localStorage לשמירת נתונים
- עברית RTL
- ממשק רספונסיבי לנייד
- עובד offline לחלוטין

## 🚀 התחלה מהירה

### 1. הורדה לטלפון
- פתח את הקישור: https://github.com/eyallev/medAeye/blob/main/clinic-booking.html
- לחץ על **Raw** (בצד ימין)
- בחר "שמור עמוד" או "הורדה"

### 2. פתיחה בטלפון
**אנדרואיד:**
- פתח את File Manager
- נווט לתיקיית ההורדות
- לחץ על `clinic-booking.html`
- בחר Chrome (או דפדפן אחר)

**iPhone:**
- פתח Safari
- גרור את הקובץ לעיר
- או: "שמור ל-Files"

### 3. יצירת קיצור דרך לשולחן הבית
**Chrome (אנדרואיד):**
- פתח את האפליקציה
- לחץ על 3 הנקודות (⋮) למעלה מימין
- בחר "הוסף לשולחן הבית"

**Safari (iPhone):**
- לחץ על "שתף"
- בחר "הוסף לשולחן הבית"

## 📚 קבצים

- **README.md** - קובץ זה

## 🔧 שימוש

### עבור מבקרים
1. הכנס את פרטי המטופל (שם, ת.ז, קופת חולים)
2. בחר תאריך בלוח השנה
3. בחר שעה זמינה (אדום = תפוס, ירוק = פנוי)
4. אשר את התור

### עבור מנהל המרפאה
1. עבור לטאב "ניהול תורים"
2. ראה כל התורים המזומנים
3. מחק תורים לפי הצורך
4. ייצא נתונים ל-JSON להעברה למחשב

## 💾 גיבוי נתונים

### אוטומטי
הנתונים נשמרים בעצמם בטלפון (localStorage) כל פעם שזימנת תור.

### ידני
1. עבור ל"ניהול תורים"
2. לחץ על "📥 ייצוא נתונים (JSON)"
3. הקובץ יורד כ-`clinic-bookings-[תאריך].json`
4. עכשיו יש לך גיבוי!

### שחזור
אם תמחקת את הנתונים בטעות:
1. העתק את תוכן ה-JSON
2. פתח את console ב-DevTools (F12)
3. הדבק: `localStorage.setItem('clinicBookings', '[paste JSON content here]')`

## 🐛 תיקוני באגים / בעיות

### הנתונים נמחקו
- אם סגרת את Browser עם "סגור כל הטאבים", הנתונים עדיין שמור ב-localStorage
- נסה לפתוח שוב את הדף

### הטלפון קפא
- עדכן את האפליקציה (הורדה חדשה של הקובץ)

- בדוק ש-`CLINIC_HOURS` בקוד תואם לשעות הפתיחה שלך
